# MusicInsta Piano source assets

`compositions.json` is the shared composition source for the six original launch arrangements. `render_audio.py` renders backing-only WAV files with a custom synthesizer and no third-party samples. The interactive piano line is generated in the browser from the deterministic chart data only after successful hits.

The two PNG contact sheets are original project artwork generated with OpenAI ImageGen and cropped into production-sized JPEG assets. Prompt summary: three dark MusicInsta rhythm environments (cosmic, studio and Johannesburg night) and six distinct fictional piano-track covers, with no baked interface text or logos. The supplied MusicInsta logo remains the production brand asset.
