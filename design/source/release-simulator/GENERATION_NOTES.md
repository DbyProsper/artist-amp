# Release Day Simulator artwork

Generated for the MusicInsta Release Day Simulator on 2026-11-09 with the built-in image generation workflow.

## Direction

- Contemporary semi-realistic editorial illustration.
- Fictional South African adults and locations.
- Charcoal, MusicInsta pink, violet and warm practical lighting.
- No embedded UI, labels, logos or authoritative maps.
- Recurring identities were generated in coordinated campaign story sheets and then exported as web-optimised scene assets.

## Source sheets

The generation set contains one coordinated six-scene sheet for each campaign, one eight-character portrait sheet, and one background/hub sheet. Production crops are stored in `public/assets/games/release-simulator/` and referenced through `src/lib/games/releaseSimulatorAssets.ts`.

## Brand assets

The supplied `MusicInsta universe logo.png` is used as the transparent musical-planet symbol. It is overlaid by the application and was not regenerated inside scene artwork.
