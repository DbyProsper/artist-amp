# MusicInsta Flappy asset generation

The production raster artwork was generated with the built-in image-generation tool using the supplied MusicInsta concept board and logo as visual references.

- Cosmic Groove: purple deep-space scene with ringed planets, crystals and orbital speakers.
- Neon Studio: charcoal production room with magenta/violet lighting, consoles and equaliser walls.
- Jozi Skyline: Johannesburg-inspired sunset cityscape with layered rooftops and speaker rigs.
- Obstacles: transparent, collision-readable crystal, equaliser-speaker and rooftop-speaker columns.
- Mascot: symbol-only MusicInsta musical planet, isolated from the supplied logo reference.

Generated scenes intentionally exclude the player, HUD, buttons, scores and pickups. Public assets are resized and compressed for web delivery. Mid/near parallax, pickups and celebration graphics are deterministic SVG assets so they remain lightweight and crisp.
